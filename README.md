# 200만 년 전에서 살아남기

국립중앙과학관 **인류관** 전시와 연계한 고등학교 수업용 웹앱입니다.
학생 폰 브라우저 하나로 돌아갑니다. **앱 설치·로그인·계정·서버가 필요 없습니다.**

**바로 열기 → https://illyugwan.vercel.app**

---

## 수업에서 어떻게 쓰나 (총 4차시)

| 차시 | 단계 | 학생이 하는 일 |
|---|---|---|
| 1~3차시 | ① 전시 탐색 | 인류관을 돌며 문제 10개의 답을 **전시 패널에서** 찾습니다 |
| 1~3차시 | ② 환경 판단 | 제시된 환경에 가장 잘 맞는 인류 속을 고르고, **전시에서 찍은 증거 사진**과 함께 이유를 적어 제출합니다 (라운드당 5분 · 3라운드 필수 + 1라운드 선택) |
| 1~3차시 | ③ AI 검증 | AI가 쓴 원시 환경 묘사에서 **사실과 다른 곳**을 찾아냅니다 |
| 1~3차시 | ④ 엔딩 | 왜 사피엔스만 남았는지 보여주는 Canvas 장면이 자동으로 흘러갑니다 |
| 4차시 | ⑤ 자가진단 | "나는 어떻게 진화했을까" — 문항 10개에 답하며 원시 행동과 현대 생활의 미스매치를 하나씩 확인합니다 |
| 4차시 | ⑥ AI로 시대 구현 | Google AI Studio 등 **앱 밖 생성형 AI**로 한 시대를 직접 구현해보고, 그 결과에서 오류를 스스로 찾아 프롬프트·결과·비평을 기록합니다 |
| 4차시 | ⑦ 닫는 이야기 | 호기심→과학→가상세계→AI로 이어진 인류사를 "그걸 쓰는 건 여전히 사바나의 그 뇌"로 되돌려 마무리합니다 |

①~④는 한 번에 이어지는 흐름이고(1~3차시에 걸쳐 운영), ⑤~⑦은 선생님 안내가 있을 때 별도로 시작하는 4차시 전용 활동입니다(자가진단 → AI로 시대 구현 → 닫는 이야기 순으로 한 흐름).

### 핵심 설계

- **전시 탐색 10문항은 인류관 동선을 그대로 따라갑니다.** 인류의 기원·진화(사헬란트로푸스~초기 인류 세 그룹~석기~한반도 화석~상징적 표현)에서 시작해, 문명의 발달(추상언어와 문자, 농업과 정착생활)까지 살짝 걸칩니다. 문명·과학사 전시 구역(국가의 출현, 통신, 과학혁명, 가상현실 등)은 주제가 크게 벌어지고 4차시 안에 다 담기 어려워 의도적으로 뺐습니다.
- **환경 판단 라운드는 사진 증거 + 최소 8자 이유를 써야 제출됩니다.** 둘 중 하나라도 없으면 제출 버튼이 비활성화되고, 5분이 다 되면 자동으로 "시간 초과"로 제출됩니다.
- **근거로 쓴 문장은 키워드 기반으로 채점됩니다.** 정답 속에 맞는 근거를 댔는지, 아니면 다른 속에 더 어울리는 근거를 댔는지, "뇌가 커서/힘이 세서"처럼 흔한 오개념인지를 구분해 피드백을 줍니다. 서버·AI 호출 없이 전부 로컬 키워드 매칭입니다.
- **환경마다 정답 속이 다릅니다.** 파란트로푸스가 정답인 환경도 있어요 — 한 가지(강한 턱)에 강하게 특화된 쪽이, 그 조건이 사라지면 오히려 먼저 무너진다는 걸 엔딩에서 보여줍니다.
- **모닥불은 함정입니다.** 불 사용 시기는 학계가 아직 다투는 중이라, AI 검증에서 거짓으로 단정하면 기록에 남습니다. "모르는 것"과 "틀린 것"을 구분하게 하는 장치입니다.
- **4차시는 ①~④의 마무리입니다.** 세상은 언어·농업·문명·과학으로 1만 년 만에 빠르게 바뀌었지만, 그걸 다 쓰는 우리 몸은 그대로라는 데서 출발해 — 그 적응이 지금 나에게 어떻게 남아 있는지로 끝맺습니다.
- **AI 활동은 3차시 AI 검증을 뒤집은 것입니다.** 3차시에서는 "AI가 쓴 거짓을 찾아내는" 소비자 역할이었다면, 4차시(⑥)에서는 학생이 직접 AI에게 시대를 구현하게 한 뒤 그 결과에서 오류를 찾는 **창작자+검증자** 역할을 합니다. 같은 비판적 사고를 대상만 바꿔 한 번 더 적용하는 구조예요. AI 호출은 앱이 아니라 **학생이 쓰는 외부 AI(Google AI Studio 등)**에서 일어나고, 앱은 프롬프트·결과 요약·비평 세 가지만 기록합니다 — 그래서 "서버·API 없음" 원칙이 유지됩니다.

### 평가 자료

결과 화면(1~3차시 종료 시)에 기록 세 가지가 남습니다.

- **전시 탐색** — 10문제 중 몇 개를 찾았나 (몇 번 만에 맞혔는지는 목록 화면의 ★ 한 번에 / ☆ 두 번 / · 세 번 이상으로)
- **AI 검증** — 거짓 몇 개를 찾았나 / 맞는 걸 몇 번 잘못 짚었나 / 논쟁 항목을 단정했나
- **환경 판단** — 라운드 몇 번 중 몇 번 정답을 골랐나, 라운드별로 고른 속·적은 이유·증거 사진이 로그로 남습니다

4차시는 자가진단 10문항 응답과 **AI로 시대 구현 활동(프롬프트·AI 결과 요약·학생 비평)**이 하나의 payload(`aiBuild`)로 함께 제출됩니다. 두 제출(1~3차시 / 4차시) 모두 지금은 `sendToTeacherPlatform()`이 브라우저 `localStorage`에 저장만 하고, 실제 교사 플랫폼(Muse-X) 전송은 아직 연결되어 있지 않습니다 — 코드의 `TODO(다른 개발자 작업 예정)` 주석 참고.

## 문항 고치는 법

**⚠️ 문항은 실제 전시 패널을 확인한 뒤 수정해야 합니다.**
10문항 중 **m6(석기 대량생산) · m7(한반도의 인류 화석) · m8(상징적 표현) · m9(추상언어와 문자) · m10(농업과 정착생활)**은 2026-10-13 현장 사진으로 패널 문구를 직접 확인했습니다(전사본: **`docs/전시패널-원문.md`**). 나머지(**m1~m5**)는 이전 세션에서 국립중앙과학관 공개 자료를 근거로 작성된 것이라, 패널에 그 문구가 정확히 그대로 있는지는 아직 답사로 재확인이 필요합니다. m1~m5는 전시 **전반부**(인류의 탄생·진화 분기도·초기 인류 세 그룹·석기 제작)라 2026-10-13 촬영분에 **포함되지 않았습니다**. **답이 전시에 없으면 학생이 찾을 수 없습니다.**

`index.html` 한 파일이 전부입니다. 열어서 `MISSIONS` 를 찾으세요.

```js
var MISSIONS=[
 {id:"m1", zone:"인류의 탄생", title:"가장 오래된 인류",
  hint:"인류의 탄생 구역, 가장 처음 나오는 패널",   // 틀렸을 때 알려줄 위치
  q:"전시에서 소개하는 <b>가장 오래된 인류</b>는?",
  opts:["사헬란트로푸스 차덴시스", "...", "...", "..."],
  a:0,                                              // 정답 번호 (0부터)
  fb:"맞혔을 때만 보여줄 해설"},
 ...
]
```

- `a` 는 **0부터** 셉니다. 선택지 순서는 화면에서 매번 섞이므로 신경 쓰지 않아도 됩니다.
- 예전 버전에 있던 `unlock`/`utx`(장비 잠금) 필드는 더 이상 쓰지 않습니다. 지금은 미션을 다 풀지 않아도 다음 단계(환경 판단)로 넘어갈 수 있어요 — 강제로 막아두지 않았습니다.

## 환경 판단 라운드 고치는 법

`ERAS`(eA~eD, 시대별로 카드 10장씩) · `GENUS_INFO`(6개 속 설명) · `TRAIT_LIB`(근거 키워드 사전)를 찾으세요.

- 라운드가 시작되면 해당 시대 카드 10장 중 하나를 무작위로 보여줍니다.
- `eA`(약 700만 년 전)와 `eC`(약 10만 년 전)는 `existenceOnly:true` — 그 시대에 **존재가 확인된 속이 하나뿐**이라 사실상 정답이 고정됩니다.
- 학생 글에서 `TRAIT_LIB`의 `kw`(키워드)를 찾아 피드백을 자동 생성합니다. 키워드를 늘리면 더 다양한 문장을 인식합니다.

## AI 묘사 고치는 법

`aiTokens` 함수를 보세요.

```js
{t:"매머드", k:"err", cat:"대륙", why:"대륙이 틀렸습니다. ..."},
{t:"아카시아 나무", k:"ok", why:"맞습니다. ..."},        // 함정 (정상 서술)
{t:"모닥불", k:"deb", why:"단정할 수 없습니다. ..."},     // 논쟁 항목
{t:"그냥 지나가는 문장"}                                  // k 없으면 클릭 불가
```

- `k` — `err`(거짓) / `ok`(정상, 함정) / `deb`(논쟁)
- `cat` — 오류 종류(시대/대륙/식생/생물 등). 결과 화면에 태그로 표시됩니다.

## 4차시 자가진단 고치는 법

`SELF_ITEMS` 배열(10문항)을 찾으세요. 문항마다 `q`(질문) · `ancient`(원시 환경에서의 기능) · `brain`(뇌 메커니즘) · `modern`(현대의 미스매치) 네 가지를 적습니다. "나도 그래요" / "난 아니에요" 어느 쪽을 고르든 같은 해설이 나옵니다 — 맞고 틀림이 아니라 자기 인식을 위한 문항입니다.

## AI로 시대 구현 활동 고치는 법

안내 문구를 바꾸려면 `vBuild` 섹션(HTML)을 열어 프롬프트 가이드를 수정하세요. 어떤 외부 AI를 쓰게 할지는 학교 사정에 맞게 안내 텍스트만 바꾸면 됩니다(기본은 Google AI Studio). 학생은 프롬프트·AI 결과 요약·비평 세 칸을 모두 채워야 "작성 완료"가 활성화됩니다(각각 최소 10/10/5자 — `checkBuildEnabled()`에서 조정). AI 호출 자체는 앱이 하지 않으므로 API 키·비용·외부 전송이 전혀 없습니다.

## 다른 플랫폼에 올리기

**`index.html` 파일 하나가 전부입니다.**

- 빌드 과정 없음 (npm, 컴파일, 번들러 전부 불필요)
- 서버 없음, 데이터베이스 없음, API 호출 없음
- 외부 의존성은 **구글 폰트 하나뿐**이고, 그마저 없어도 시스템 글꼴로 정상 동작합니다
- 학생 기록은 지금 브라우저 `localStorage`에만 저장되고 밖으로 나가지 않습니다 (교사 플랫폼 전송은 TODO)

그래서 **정적 파일을 올릴 수 있는 곳이면 어디든** 됩니다.

| 올릴 곳 | 방법 |
|---|---|
| GitHub Pages | 저장소 Settings → Pages → 브랜치 지정 |
| Netlify / Vercel / Cloudflare Pages | 저장소 연결하면 끝 (빌드 설정 없음) |
| 학교 홈페이지·웹서버 | `index.html`을 그대로 업로드 |
| LMS(구글 클래스룸, 위두랑 등) | 파일 첨부 또는 링크 |
| 다른 페이지 안에 삽입 | `<iframe src="..." width="100%" height="800">` |
| 인터넷 없는 환경 | 파일을 USB로 옮겨 브라우저로 직접 열기 |

마지막 항목이 중요합니다. **과학관 와이파이가 불안정해도 파일만 있으면 돌아갑니다.**

## 아직 확인되지 않은 것

- 문항 10개 중 **m1~m5**의 답이 실제 전시 패널에 그 문구 그대로 있는지 — 답사 필요 (m6~m10은 2026-10-13 현장 사진으로 확인함, 전사 `docs/전시패널-원문.md`). m1~m5는 전시 전반부라 이번 촬영분에 없어 아직 미확인입니다.
- 인류관 실물 조형물의 종(種) 구성
- 학급 단위 운영 시 소요 시간 — 특히 전시 탐색 10문항 + 환경 판단 라운드(5분 타이머 × 3~4회)가 1~3차시 안에 끝나는지
- 교사 플랫폼(Muse-X) 연동 — `sendToTeacherPlatform()`은 지금 `localStorage` 저장만 하는 자리표시자입니다
