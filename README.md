# 200만 년 전에서 살아남기

국립중앙과학관 **인류관** 전시와 연계한 고등학교 수업용 웹앱입니다.
학생 폰 브라우저 하나로 돌아갑니다. **앱 설치·로그인·계정·서버가 필요 없습니다.**

**바로 열기 → https://illyugwan.vercel.app**

---

## 수업에서 어떻게 쓰나

| 단계 | 학생이 하는 일 |
|---|---|
| 1. 전시 탐색 | 인류관을 돌며 문제 6개의 답을 **전시 패널에서** 찾습니다 |
| 2. 종족 선택 | 찾아낸 종족만 고를 수 있습니다 (호모 / 오스트랄로피테쿠스 / 파란트로푸스) |
| 3. AI 검증 | AI가 쓴 원시 환경 묘사에서 **사실과 다른 곳**을 찾아냅니다 |
| 4. 장비 선택 | 전시에서 연 것 + AI 검증 결과가 반영된 목록에서 고릅니다 |
| 5. 생존 | 네 장면이 자동으로 흘러갑니다. 학생은 개입할 수 없습니다 |

### 핵심 설계

- **전시를 안 읽으면 장비가 안 열립니다.** 읽어야 이깁니다.
- **AI가 쓴 거짓을 못 잡으면 그 거짓을 안고 출발합니다.** 활과 화살을 걸러내지 못하면 하이에나 앞에서 손이 비어 있습니다.
- **맞는 서술을 잘못 짚어도 감점입니다.** AI를 무조건 의심하는 것도 검증이 아닙니다.
- **모닥불은 함정입니다.** 불 사용 시기는 학계가 아직 다투는 중이라, 거짓으로 단정하면 기록에 남습니다. "모르는 것"과 "틀린 것"을 구분하게 하는 장치입니다.
- **파란트로푸스는 무엇을 들든 멸종합니다.** 게임 밸런스가 아니라 사실입니다.

### 평가 자료

결과 화면에 숫자 세 개가 남습니다.

- **전시 탐색** — 몇 문제를, 몇 번 만에 맞혔나 (★ 한 번에 / ☆ 두 번 / · 세 번 이상)
- **AI 검증** — 거짓 몇 개를 찾았나 / 맞는 걸 몇 번 잘못 짚었나 / 논쟁 항목을 단정했나
- **생존** — 살아남았나, 그리고 그림을 남겼나

## 문항 고치는 법

**⚠️ 문항은 실제 전시 패널을 확인한 뒤 수정해야 합니다.**
국립중앙과학관 공개 자료를 근거로 작성했지만, 패널에 그 문구가 그대로 있는지는 답사로 확인해야 합니다. **답이 전시에 없으면 학생이 찾을 수 없습니다.**

`index.html` 한 파일이 전부입니다. 열어서 `MISSIONS` 를 찾으세요.

```js
var MISSIONS=[
 {id:"m1", zone:"인류의 탄생", title:"가장 오래된 인류",
  hint:"인류의 탄생 구역, 가장 처음 나오는 패널",   // 틀렸을 때 알려줄 위치
  q:"전시에서 소개하는 <b>가장 오래된 인류</b>는?",
  opts:["사헬란트로푸스 차덴시스", "...", "...", "..."],
  a:0,                                              // 정답 번호 (0부터)
  fb:"맞혔을 때만 보여줄 해설",
  unlock:["band"], utx:"👥 무리"},                   // 맞히면 열리는 것
 ...
]
```

- `a` 는 **0부터** 셉니다. 선택지 순서는 화면에서 매번 섞이므로 신경 쓰지 않아도 됩니다.
- `unlock` 에 쓸 수 있는 값: `band` `water` `stone` `ochre` (장비) / `austra` `paran` (종족)

**AI 묘사**를 고치려면 `aiTokens` 함수를 보세요.

```js
{t:"매머드", k:"err", cat:"대륙", why:"대륙이 틀렸습니다. ..."},
{t:"아카시아 나무", k:"ok", why:"맞습니다. ..."},        // 함정 (정상 서술)
{t:"모닥불", k:"deb", why:"단정할 수 없습니다. ..."},     // 논쟁 항목
{t:"활과 화살", k:"err", bust:"bow", why:"..."},         // 잡아내면 장비 목록에서 잠김
{t:"그냥 지나가는 문장"}                                  // k 없으면 클릭 불가
```

- `k` — `err`(거짓) / `ok`(정상, 함정) / `deb`(논쟁)
- `bust` — 잡아내면 잠글 장비 id

## 다른 플랫폼에 올리기

**`index.html` 파일 하나가 전부입니다.**

- 빌드 과정 없음 (npm, 컴파일, 번들러 전부 불필요)
- 서버 없음, 데이터베이스 없음, API 호출 없음
- 외부 의존성은 **구글 폰트 하나뿐**이고, 그마저 없어도 시스템 글꼴로 정상 동작합니다
- 학생 기록은 브라우저 `localStorage`에만 저장되고 밖으로 나가지 않습니다

그래서 **정적 파일을 올릴 수 있는 곳이면 어디든** 됩니다.

| 올릴 곳 | 방법 |
|---|---|
| GitHub Pages | 저장소 Settings → Pages → 브랜치 지정 |
| Netlify / Vercel / Cloudflare Pages | 저장소 연결하면 끝 (빌드 설정 없음) |
| 학교 홈페이지·웹서버 | `index.html`을 그대로 업로드 |
| LMS(구글 클래스룸, 위두랑 등) | 파일 첨부 또는 링크 |
| 다른 페이지 안에 삽입 | `<iframe src="..." width="100%" height="800">` |
| 인터넷 없는 환경 | 파일을 USB로 옮겨 브라우저로 직접 열기 |

마지막 항목이 중요합니다. **과학관 와이파이가 불안정해도 파일만 있으면 돌아갑니다.**
